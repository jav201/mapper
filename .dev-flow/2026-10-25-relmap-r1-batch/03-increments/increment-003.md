**Then the extraction.** `mapper/yamlscan.py` holds the one iterative prescan: `prescan(text)`, `YamlLimitError(Exception)` with `kind`
(`anchor`/`depth`), `shown`, `limit`, and `ANCHOR_NAME_DISPLAY = 40`; it is the only importer of `osopen.MAX_DEPTH`. `store.py` loses

refusal itself (`YamlLimitError` → `MapStoreError`, `from None`, the same two f-strings, `{exc.shown!r}` and `{exc.limit}`), inside the existing
`try`, ahead of the `(YAMLError, ValueError, RecursionError)` net. A `yaml.YAMLError` from `yaml.parse` still propagates to that net. The golden
stayed GREEN after the move and `tests/test_ingestion_limits.py` is unchanged and GREEN.

**`mapper/relmap/descriptor.py`** (D2 names, frozen): `read_repo_text(path, cap)` — `os.lstat`, refuse a link/reparse point (`osopen.is_link`, K1) and any non-regular
file (K2) before any open, open ONCE read-only (`O_NONBLOCK`/`O_BINARY` where present), `os.fstat` the opened file, close it, refuse a mismatch of
`st_dev`, regular-file type, or `st_ino` **only when both inodes are non-zero** (K2; security N1 + M1), then `osopen.read_capped(path, cap)` with
the `ContentReadError` text classified by prefix to K5/K6/K7, any other `OSError` K4, a missing file K3. `RepoReadError(cause, limit)`,
`DescriptorError(cause, name, limit=None)` (message = base name + cause only), frozen `Descriptor(profile, canon, us_canon, at_table,
ignored_keys)`, `default_descriptor()`, `load_descriptor(path, repo)` (read → `prescan` → `safe_load`; anchor K8, depth K9, any
`YAMLError`/`ValueError`/`RecursionError` K10; the schema table K11–K16; `confine_reason` on `us_canon`/`at_table` K17, never opened),
`discover_descriptors(repo)` (`*.relmap.yml`, case-sensitive, sorted by code point, at most 8 plus the overflow count; links, directories
and other entries are listed so reading refuses them), `CAUSE` (`types.MappingProxyType`, K1–K17; K5 stored without its number, K16/K17 are
templates), and `refusal_line(base_name, cause, limit=None)` (the base name cut to 120 with `model.cut`, K5 rendered `exceeds the 8388608 byte
limit`). Placement of `refusal_line` is §6 item 4.
