## 5 · Things that will bite on restart

- **`legacy_windows=False` is mandatory** in every prototype `Console(...)`, or rich reserves the
  last column, rows wrap, and the frame shears. The same call also needs `record=True`,
  `force_terminal=True`, `color_system="truecolor"` and
  `file=open(os.devnull,"w",encoding="utf-8")` — without the `file=`, Windows cp1252 chokes on
  the Unicode.
- Run everything with `PYTHONUTF8=1 PYTHONIOENCODING=utf-8`. Reading `state.json` and printing it
  without those fails on `\u21b5`.
- **Suffixed ids are a named hazard.** `AT-[0-9]{3}` is blind to `AT-007b`; `(V\d+)` skips
  `V4a`/`V4b`. Both defects shipped months apart from the same blind spot, in instruments built
  to catch transcription errors. **The instrument is not exempt from the defect it hunts.**
- Close shape is **stage-committed**: source lands at each acknowledged stage, then a docs commit
  records the close. Commit early at green points — this project has a history of session expiry
  mid-increment.
- Never stage `prototypes/`, `mapper.db`, or scratch artifacts.
- Username paths are **REDACTED in the vault copies** at `dev-flow-sync`; originals stay intact.
  Committed transcripts contain the operator's username — a declared blocker for any public push.
